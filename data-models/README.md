# Data Models

Centralized shared data-model layer for the Manish Vaghasiya platform.

## Purpose

This package is the future single source of truth for:

- persistent entities
- shared domain contracts
- schema defaults
- validation-friendly field structure

## Current Scope

The first shared model moved into this package is:

- `Subscriber`
