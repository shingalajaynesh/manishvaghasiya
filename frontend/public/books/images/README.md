# Book Images Directory

Place all **Book Cover**, **3D Mockup**, and **Inside Preview** images in this folder.

### Recommended File Names:
- `cover.jpg` (or `cover.png` / `cover.webp`) - Main Book Front Cover
- `mockup.png` - 3D Book Mockup Display Image
- `preview-1.jpg` - Inside Chapter Preview Page 1
- `preview-2.jpg` - Inside Chapter Preview Page 2

### Image URL:
Once added, your images can be accessed at:
`/books/images/cover.jpg`
`/books/images/mockup.png`
