# Frontend App

Frontend application for the Manish Vaghasiya platform.

## Stack

- React
- Vite
- TypeScript
- Tailwind CSS

## Source Structure

```text
src/
|-- app/        # app shell and root composition
|-- content/    # shared content and site-level config
|-- features/   # feature-specific UI and content modules
|-- pages/      # page-level composition
`-- shared/     # reusable site components and utilities
```

## Commands

```bash
npm run dev
npm run build
npm run preview
```
